＜いったんまとめ＞
低周波と高周波を組み合わせた入力に対して、全体の位相分布が固有振動数に強い影響を受けることがわかった。
特に、より固有振動数に近しい入力成分に近づこうとすることがわかり、逆に平均周波数での分布はむしろ内部の同期を完全に乱した。

また、非線形タスクにおいて、これは想定されていたことではあるが、全くひどい結果だった。
そもそも理論的にリザバーでの近似ができない？ため、処理自体で過去の情報が失われているようだった。

蔵元リザバー自体は、入力系列の力学系を近似するものであり、それまでの過去情報を記録するものではない。
しかし、むしろ滑らかな力学系で生成された系列に関しては通常のRCよりはるかに優れた記憶容量を満たすことが考えられる。
