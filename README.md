＜RCにおけるHPチューニング＞

RCにおいて、どのようにHPをチューニングするだろうか？
ESNに関して言えば、ノード数、正規化係数、リーク率などだろうか。特に正規化係数はとても敏感で、タスクのスケールに強く依存していた。
また、そう簡単には変えられないものの、より精度を高めたいのであればトポロジーや接続も重要である。
そして、RCの性能はカオスの淵でしばしば語られる。パラメータ設定により、過去の履歴で飽和するカオスと、一切記憶されない秩序の二極化し、
その境のカオスの淵で性能が最も良くなると言う話である。しかし、これもタスク依存の話であり、必要な性質はカオスと秩序を彷徨っているのが実態だ。
では、入力の過去履歴への依存度に応じて、適応的にトポロジー、重みを更新することで、特定のサイズにおけるRCの最大の性能を引き出せないだろうか？

とりあえず、蔵元モデルを「短期記憶能力を持ち、時系列を高次元の時空間パターンに変換する」機構として用いたい。その上で考えられる問題点として、1.位相に対して入力が影響する位相の変化量が小さすぎる
2.位相のダイナミクスの方が大きくて入力の変動が引っ張られる
こういった問題があった。そこで、位相の変化量に注目して出力を位相の変化量で求めることにした。特に、入力とそれまでの状態に注目してtheta’-omegaとした。

これに関してNARMA10でn=200,dt=0.01,alpha=0.1,s=1で接続を[0, 1]のランダム一様分布から求めたところ、
MSE: 0.0037
RMSE: 0.0604
NRMSE: 0.5841
という結果が得られた。特にNRMSEにおいて、1から0.5まで改善した点から、この改良によって少なくとも予測自体はうまく行えるようになったと言える。一方で、短期記憶能力を図るためのランダム信号の遅延復元タスクにおいてはNRMSE: 0.9993と、非常に悪い精度であり、グラフの概形もラベルのスケールから大きく萎んだものであった。このことから、NARMA10での移動平均に対する予測精度が向上したものの、依然として特定ステップの入力に関する短期記憶はほぼ無いと考えられる。

この時点で非常に興味深いのは、そもそも再帰入力にあたる位相差自体は元の入力信号の空間、スケールから完全に逸脱したものである点である。また、オーダーパラメータが0.99とほぼ同期状態にあるのも興味深い点である。

さて、この時、一見すると同期しているためにノード位相までもがほぼ同じで表現能力が著しく低下しているように見えるが、実際には異なる可能性がある。sin関数に注入している入力により、あえて同期状態に揺らぎを生じさせる。特に固有周波数の違いによって同期状態であり続けるために位相の変化量を一定にし続けるためには、位相の変化量の更新則における第２項を一定値に撮り続ける必要があり、もし位相差が完全にゼロであったらこの項自体がゼロとなって元の固有周波数で周り始める。そしてそこで生じたわずかな位相差からまた完全に位相がかぶるような状態に移行すると考えられる。

この点はあまり元の蔵元モデル系の話で見ない気がする。おそらく、理論的にはdtがゼロに飛ばされるため、無視されているのだろう。しかし、実際のシミュレーションではむしろそのわずかなずれによって、一見完全に同期しているように見えるモデル内部で摂動が生じ、それがsin波の異なる部分での非線形処理を行わせることによって表現能力が向上している可能性がある。

この時、固有周波数の分布が精度に大きく影響する可能性が考えられる。

ここで重要になりそうなのは、元の固有周波数のばらつきによる、同期状態においての位相のばらつきを用いた、表現の多様性である。

蔵元モデルにおいて、実用的には同期状態でも位相にはばらつきが存在する。
これは、元の固有周波数により、一定の角速度を保つためには位相のズレで調整しているためである。そして、計算上位相差は固有周波数分布に依存しており、これを活用することで同期状態から多様な表現を引き出せる可能性がある。

さて、実際に計算してみると、θi-bar(theta)=Arcsin((bar(theta')-omega)/K)と表せる。そして、ωが正規分布であった場合、全てのノードらにおける位相のずれは正規分布をarcsin関数に入力した後の分布となる。

さて、これを踏まえてKが一定の値で固定されており、sin関数に入力を与えてモデルが同期状態にあることを考える。この時、sinの出力はテイラー展開により、sin(Δθ)+αucos(Δθ)と表せる。そして、位相差によってcos関数の異なる勾配が用いられることがわかる。

このテイラー展開は誤っていた。実際のところ、Δθは同期状態でゼロに近づくべきで、αuも大きくはない。また6/6で記載しているが、RKに切り替えて同期状態での特徴を調べたところ、固有周波数をガウス分布として分散を大きくすると教師データのスケールからの大きな逸脱が見られた。このことから、同期状態においてΔθが十分に小さくならない場合、上記のテイラー展開によって線形変換しかできなくなって十分な表現力を持たなくなる可能性がある。

さて、実際にKを固定して実験してみると精度が致命的に悪くなった。気になる点としてはスケールが崩壊して、極端に大きくなったり小さくなったりしていた。これに関しては、出力重みの平均が-0.0099から11.466に増加していたため、根本的にモデルの近似能力が落ちていることがわかった。
