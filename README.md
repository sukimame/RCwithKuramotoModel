# RCwithKuramotoModel

4/13
Zuo 2023 では蔵元モデルを用いた自己発展リザバーを提唱している。これは、各タスクにおいて
リザバーの内部状態を慣らすための入力時系列の最初をわざと訓練なしに入力する、ウォッシュアウト
と呼ばれる期間に接続行列Kを位相差を用いた更新を行うことで、リザバー構造を各タスクに特化させるような
手法である。実際にこの論文では、リザバーの接続の分布が初期化によらず安定し、またin vivoでの接続分布に
酷似しており、またモデルの性能に関してもESNと比べて面的に広がっている。

特に個人的に興味深いのは、SAD-RCでは蔵元振動子モデルの相転移現象での臨界点付近へのリザバー構造の
移行を行なっているかもしれない点である。接続行列の更新により、完全な非同期状態や同期状態からその臨界点
付近に
